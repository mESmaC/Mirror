Mirror Design System

v0.1 · review sample
single file · no external assets
hover / focus are live — matrices also show forced states

Foundations for Mirror's native desktop: color, typography, spacing, icons, and reusable controls, each with light and dark themes and hover, focus, pressed, disabled, and error states. Everything on this page is plain HTML/CSS using system font stacks, so it renders offline and maps directly to tokens we can later implement in the shell renderer.

00 — Principles

Design principles

P1

Calm by default

Quiet neutrals carry the interface. Color is reserved for meaning: one accent, four semantic states, nothing decorative.

P2

One accent, used sparingly

A single teal marks the primary action, the focused element, and the running app. If everything is accented, nothing is.

P3

Honest layers

Elevation comes from subtle borders and soft shadows — desktop, window, popover — never from heavy glows or gradients on controls.

P4

Keyboard first

Every control has a visible focus ring and a reachable tab stop. Pointer-only interactions are bugs, not features.

Window chrome

Windows are 12 px radius cards at elevation e3 with a 38 px titlebar: app tile, title, and 38 × 28 px caption buttons. Close is the only red hover; minimize and maximize use the neutral overlay. Unfocused windows drop to e1, soften their title text, and mute the app tile — no content is hidden.

MOTION

120 / 200 / 320 ms

Fast for hover and focus, medium for menus and window open, slow for minimize. Standard ease cubic-bezier(.4,0,.2,1). All non-essential motion is removed under reduced-motion.

LAYERS

z-order contract

Desktop 0 · windows 10–99 · dock 100 · menus 200 · notifications 300 · tooltip 400 · cursor topmost. Nothing escapes this order.

DENSITY

One default density

32 px controls, 13 px labels, 8 px gaps. A compact 28 px variant exists for list rows and is opt-in per surface.

THEMES

Peer themes, one structure

Light and dark implement the same token names; apps never pick raw colors, so a theme switch is a palette swap, not a redesign.

08 — Accessibility

Contrast & interaction guarantees

Ratios below are measured (WCAG 2.x relative luminance) for the shipped token pairs. Normal text targets AA 4.5:1; large text and UI boundaries target 3:1.

  • Focus is always visible. A 2 px accent ring with offset; nothing is focused by color change alone.
  • Errors are icon + text. Danger borders always pair with a glyph and a written reason.
  • Targets ≥ 28 px. Caption buttons 38 × 28, dock tiles 42, controls 32 tall.
  • Reduced motion respected. Indicators fall back to static states; spinners become “working…” labels.
  • Disabled means unavailable, not invisible. 45 % opacity, but labels stay legible and focus is skipped.
  • Both themes pass the same table. No theme is a second-class citizen.
