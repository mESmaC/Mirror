Status: confirmed (2026-10-10). Delivered in two parts: everything except D9 lands next, right after the 0010 stack is merged; D9 (window-chrome geometry) lands together with 0017c, before 0018's Mirror rows.

## Goal
The shell, its apps (Notes and Counter), the kernel boot screen and the kernel console look like Kimi's dark theme (`docs/design/design-system.html`) as far as today's renderer can draw it: opaque, palette-indexed rectangles, 1 px borders and the 5x7 font at whole-number scales, with no alpha. Every color and chrome dimension comes from one token crate, `mirror-ui-tokens`, shared by the kernel, the shell and the apps, so 0027a's compositor and 0086's text stack can reuse it. Today colors live in three unrelated tables (`userspace/desktop/src/render.rs:31-47`, `userspace/app/src/render.rs:14-24`, `kernel/src/framebuffer.rs:199-204`), Notes is light paper in a dark shell, and Counter has a blue accent. Windows get the design's 38 px titlebar and 38x28 caption buttons, focus gets a visible ring, and errors get written text with a recovery action.

## Non-goals
- Alpha and what needs it: soft shadows, the 32% `--ring` halo, 45% disabled opacity, glass and blur, the gradient wallpaper (0027a; review note 10 keeps v1 opaque). Elevation here is border-only.
- Rounded corners and circles (0027a, antialiased RGBA surfaces); icons (0086's rasterizer: caption buttons keep a bar and an `x`, the app tile shows a letter).
- Real fonts, weights, in-between sizes and non-ASCII text (0086, S11). The three copies of the 5x7 font stay.
- Motion, an animation clock and the reduced-motion preference (0027a, 0068). Nothing animates today, so the reduced-motion rule already holds.
- The light theme on screen (D2: 0068 and 0088). Its tokens are defined and tested, never drawn.
- New apps and shell surfaces such as the dock, start menu, palette, switcher and notifications (Files and Settings 0088, Terminal 0082; the desktop chrome has no owner yet, a G12 gap). The top bar, taskbar, launchers and task buttons keep their geometry.
- Keyboard model: Esc still exits to the console and Tab still cycles windows (`shell.rs:377-391`) until 0084, so caption buttons and the new Relaunch button stay pointer-only.
- Window sizes, resize, snapping, a third window, the 1280x800 cap (0027a, 0069), and the animated boot of `boot-animation.html` (no owner; review note 7). The boot screen keeps its real 35/70/100 progress.
