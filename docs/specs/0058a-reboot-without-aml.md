## Goal
Typing `restart` at the kernel console restarts the machine through S16's sequence: the FADT reset register (validated fail-closed), the 8042, port 0xCF9, then a triple fault, each attempt time-bounded and announced by a content-free marker in every flavor. VMware reboots through its firmware's register and boots Mirror again without host action, as the vmrun lane and Phase 0's exit need (`roadmap-replan.md:107-111`).

## Non-goals
- AML, `_S5` and the power button (0057); orderly shutdown: service stop, filesystem sync and the clean-pool marker (0058).
- Panic reboot (S17, 0051); the panic handler (`kernel/src/main.rs:1498-1511`) is unchanged.
- UEFI `ResetSystem` (S16 excludes it; Mirror requests no EFI system table, `kernel/src/boot.rs:13-57`), the 0x472 flag, port 0x92 and BIOS restart.
- Restart from userspace: a syscall (0020), shell or desktop control (0058's power object, Phase 5), Ctrl+Alt+Del (unplaced: 0084a routes shortcuts, and the reboot right arrives with 0058's power object in Phase 5), VMware Tools OS_Reboot (0087c).
- Memory-space and PCI-space reset registers (D2); physical-hardware quirks (G3).
